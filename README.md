A program that writes one one-line joke about working beside an AI coding agent, for make.fun's "The joke about the demo" bounty ($35 in USDC). The joke was picked from seven drafts, ranked against the judge's own criteria: on-subject first, then surprise, truth from the demo, economy, freshness.

## Run it

```sh
python3 main.py
```

It writes the joke to `/output/entry.txt` (194 characters, one line).
